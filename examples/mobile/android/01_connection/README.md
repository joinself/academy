# 🔗 Mobile Connections

> **📖 Learn the concepts first:** [Secure Connections Concepts](../../../../docs/concepts/secure-connections.md)

This directory contains mobile examples for Self SDK connections with built-in UI components.

## 📱 Examples Overview

| Example | Summary | Platform |
|---------|---------|----------|
| **02_qr** | Scan QR codes to connect with camera UI | Android, iOS |
| **03_client** | Connect to server addresses with mobile UI | Android, iOS |

## 🚀 Quick Start

### Android
```bash
cd 02_qr/android && ./gradlew run
cd 03_client/android && ./gradlew run
```

### iOS
```bash
cd 02_qr/ios && xcodebuild -project SelfSDKExample.xcodeproj
cd 03_client/ios && xcodebuild -project SelfSDKExample.xcodeproj
```

## 📱 Mobile Features

- **QR Scanner**: Built-in camera UI for QR code scanning
- **Touch Interface**: Mobile-optimized connection screens
- **Camera Integration**: Direct camera access for QR codes
- **Connection UI**: Pre-built connection management screens

## 🎯 Learning Path

1. **02_qr** → Scan QR codes to connect to services
2. **03_client** → Connect to server addresses from mobile
