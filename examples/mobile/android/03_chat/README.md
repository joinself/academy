# 💬 Mobile Chat

> **📖 Learn the concepts first:** [Message Layer Security](../../../../docs/concepts/message-layer-security.md)

This directory contains mobile examples for Self SDK messaging with built-in UI components.

## 📱 Examples Overview

| Example | Summary | Platform |
|---------|---------|----------|
| **01_basic** | Secure messaging with mobile chat UI | Android, iOS |

## 🚀 Quick Start

### Android
```bash
cd 01_basic/android && ./gradlew run
```

### iOS
```bash
cd 01_basic/ios && xcodebuild -project SelfSDKExample.xcodeproj
```

## 📱 Mobile Features

- **Chat UI**: Pre-built messaging interface
- **Real-time Messages**: Live message updates
- **Touch Interface**: Mobile-optimized chat experience
- **Push Notifications**: Message alerts
