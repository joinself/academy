# 📂 Mobile Existing Account

Load saved accounts with biometric authentication and mobile UI.

## 📱 Features

- **Account Loading UI**: Pre-built account access screens
- **Biometric Auth**: Fingerprint/Face ID verification
- **Secure Storage**: Platform-specific keychain/keystore
- **Mobile UX**: Touch-friendly interface

## 🚀 Quick Start

### Android
```bash
cd android && ./gradlew run
```

### iOS
```bash
cd ios && xcodebuild -project SelfSDKExample.xcodeproj
```

## 📱 What You'll Learn

- Mobile account loading patterns
- Biometric authentication
- Secure mobile storage access
- Mobile UI integration
