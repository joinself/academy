# Licenses

Welcome to the Self Academy licenses section. This page provides access to all licensing information related to our software development kits (SDKs), tools, and resources.

## Overview

Our licensing structure is designed to provide clear, transparent terms for developers and organizations using Self's technology. We offer a variety of license types to accommodate different use cases and requirements.

## License Categories

### Open Source Licenses

Our open source components are distributed under various permissive licenses that allow for broad usage while maintaining proper attribution and legal protection.

#### Android SDK Licenses
The Android SDK and related components are licensed under the following terms:

- **[Apache License 2.0](./open_source/android/Apache.md)** - Primary license for most Android SDK components
- **[MIT License](./open_source/android/MIT.md)** - Used for specific utility libraries and tools
- **[BSD 2-Clause License](./open_source/android/B2D_2Clause.md)** - Simplified BSD license for certain components
- **[BSD 3-Clause License](./open_source/android/B2D_3Clause.md)** - Standard BSD license with additional terms

#### iOS SDK Licenses
The iOS SDK and related components are licensed under the following terms:

- **[Apache License 2.0](./open_source/ios/Apache.md)** - Primary license for most iOS SDK components
- **[MIT License](./open_source/ios/MIT.md)** - Used for specific utility libraries and tools
- **[ISC License](./open_source/ios/ISC.md)** - Simplified permissive license for certain components

## Key Principles

Our licensing approach is guided by several key principles:

- **Transparency**: All licenses are publicly available and clearly documented
- **Permissive**: We use permissive open source licenses that encourage adoption and contribution
- **Compatibility**: Our license choices ensure compatibility with most commercial and open source projects
- **Attribution**: Proper attribution is maintained while allowing for broad usage

## Understanding License Types

### Apache License 2.0
The Apache License 2.0 is our primary license choice for SDK components. It provides:
- Patent protection for contributors and users
- Clear terms for commercial use
- Compatibility with other open source licenses
- Protection against patent litigation

### MIT License
The MIT License is used for utility libraries and tools. It offers:
- Maximum permissiveness
- Simple and clear terms
- Wide compatibility with other licenses
- Minimal restrictions on usage

### BSD Licenses
BSD licenses are used for specific components and provide:
- Simple permissive terms
- Clear attribution requirements
- Compatibility with proprietary software
- Minimal legal complexity

### ISC License
The ISC License is functionally equivalent to the MIT License but with updated language:
- Modern, clear language
- Same permissive terms as MIT
- Simplified legal text
- Broad compatibility

## Compliance and Usage

When using our SDKs and tools, please ensure you:

1. **Review the specific license** for each component you use
2. **Maintain copyright notices** and license headers
3. **Include license text** in your distribution if required
4. **Comply with attribution requirements** as specified in each license

## Questions and Support

If you have questions about our licensing terms or need clarification on specific license requirements, please refer to the individual license documents or contact our support team.

For legal questions regarding licensing, we recommend consulting with your legal counsel to ensure compliance with all applicable terms and conditions.
