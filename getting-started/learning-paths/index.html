    Learning Paths¶

    Choose the learning path that best matches your background and goals. Each path is designed to guide you from your current level to building production-ready identity solutions with Self.

    New to Identity Tech?¶

    If you're new to decentralized identity, blockchain, or cryptographic concepts, start here to build a solid foundation.

    What You'll Learn¶

    • Core Concepts: Understanding DIDs, verifiable credentials, and cryptographic foundations
    • Identity Principles: How decentralized identity differs from traditional systems
    • Security Fundamentals: Cryptographic concepts that power Self's technology
    • Real-World Applications: How these concepts solve actual problems

    Recommended Path¶

    1. Begin with Concepts: Start with the overview to understand the big picture
    2. Understanding Decentralized Identity: Dive deep into how digital identity works
    3. Secure Connections: Learn about cryptographic handshakes and secure communication
    4. Verifiable Credentials: Understand how credentials work in practice
    5. Message Layer Security: Learn about secure messaging protocols

    Time Investment¶

    • Foundation: 2-3 hours to understand core concepts
    • Deep Dive: 4-6 hours for comprehensive understanding
    • Practice: 2-3 hours with hands-on examples

    Success Indicators¶

    You'll know you're ready to move forward when you can: - Explain what a DID is and why it's important - Understand the difference between centralized and decentralized identity - Explain how verifiable credentials work - Understand basic cryptographic concepts

    Ready to Code?¶

    If you have programming experience and want to start building immediately, this path focuses on practical implementation.

    What You'll Learn¶

    • SDK Integration: How to integrate Self SDK into your applications
    • Working Examples: Complete, functional code you can run and modify
    • Best Practices: Production-ready patterns and security considerations
    • Platform-Specific: iOS, Android, Go, and Java implementations

    Recommended Path¶

    1. Start with Examples: Overview of available examples and tutorials
    2. Identity Management: Create your first decentralized identity
    3. Secure Connections: Establish peer-to-peer connections
    4. Manage Credentials: Work with verifiable credentials
    5. Messaging: Build end-to-end encrypted messaging
    6. Advanced Features: Production-ready patterns

    Time Investment¶

    • Quick Start: 30 minutes to run your first example
    • Core Features: 2-4 hours to implement basic functionality
    • Advanced Features: 4-8 hours for production-ready implementations

    Success Indicators¶

    You'll know you're ready to move forward when you can: - Run the example applications successfully - Understand the client-server architecture - Implement basic authentication flows - Handle credential requests and responses

    Integrating Your App?¶

    If you're ready to integrate Self into an existing application or build a production system, this path focuses on complete solutions.

    What You'll Learn¶

    • Complete Solutions: End-to-end implementation guides
    • Production Patterns: Scalable, secure, and maintainable code
    • Platform Integration: How to integrate with existing systems
    • Best Practices: Security, performance, and user experience considerations

    Recommended Path¶

    1. View Solutions: Overview of available solution guides
    2. Authentication: Complete authentication implementation
    3. Identity Verification: Full identity verification system
    4. Digital Signatures: Document signing workflows
    5. Production Deployment: Deploy to production environments

    Time Investment¶

    • Solution Implementation: 4-8 hours per solution
    • Production Setup: 2-4 hours for deployment and configuration
    • Testing & Optimization: 2-6 hours for comprehensive testing

    Success Indicators¶

    You'll know you're ready to move forward when you can: - Implement complete authentication workflows - Handle identity verification processes - Sign documents with cryptographic signatures - Deploy and maintain production systems
